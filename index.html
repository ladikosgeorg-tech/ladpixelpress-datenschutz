2. Zweck der Erweiterung

LadPixelPress ist eine kostenlose Browser-Erweiterung zur Optimierung, Größenanpassung und Konvertierung von Bildern.

3. Verarbeitung von Bildern

Die vom Nutzer ausgewählten Bilder werden lokal im Browser auf dem eigenen Gerät verarbeitet. Die Bilder werden nicht an Server des Entwicklers oder externe Dienstleister übertragen.

4. Lokale Speicherung

Die Erweiterung kann Einstellungen zur Bildverarbeitung und Benutzeroberfläche lokal auf dem Gerät speichern. Diese Einstellungen werden nicht an den Entwickler übertragen.

5. Analyse und Tracking

LadPixelPress verwendet keine Analyse- oder Trackingdienste und zeigt keine Werbung an.

6. Weitergabe von Daten

Durch die Erweiterung erfolgt keine Weitergabe von Bildern oder personenbezogenen Daten an Dritte.
